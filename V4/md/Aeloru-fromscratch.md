## 核心问题先点明
现在 `aeloru-fromscratch` 表现失效（loss 震荡、PEM 正反馈爆炸、假“零遗忘”），**本质不是 Aeloru 机制本身不行，而是整套为「预训练模型低秩微调」设计的机制，被直接套在了「零初始化 + 低秩 + 从头冷启动」场景上，所有机制的前提假设全部不匹配**：
- W0 接近 0 → 正交惩罚、SPHeRe、PEM 的参考系全部量纲失真，梯度直接炸；
- 低秩空间本身就要承载全部表征，容量本就不足，PEM 再往里塞全局耦合，直接撑爆；
- 状态机阈值是按预训练微调的小波动标定的，从零训练波动大，全程卡死在 red 状态，稳态机制完全不工作。

下面分三档给出方案，从「只调超参就能跑」到「架构级释放全部潜力」。

---

## 一、【零代码改动：调参即可修复】最快见效
不改代码，只改超参，就能让它从“失效爆炸”变成“正常收敛、抗遗忘有效”。

### 最优基础配置（直接用）
| 参数 | 值 | 原因 |
|---|---|---|
| `neural_dynamics_iterations` | **0** | **第一步先关 PEM**。低秩从零训练是 PEM 的绝对雷区，正反馈爆炸的根源，关掉立刻稳定。 |
| `ortho_lambda` | 0.02 ~ 0.03 | 预训练微调用 0.1 是因为 W0 已经成熟；从零训练 W0 还在长，满强度正交惩罚会直接把训练摁死。降到 1/3~1/4 才合理。 |
| `lr` | 3e-4 | 从零训练低秩不能用微调的 1e-3，步长太大会加剧震荡，降到 3e-4 稳定性大幅提升。 |
| `merge_every` | 200 | 从零训练低秩增量涨得极快，200 步合并一次，及时把增量折叠进 W0，既释放低秩空间，也逐步建立 W0 参考系。 |
| `red_conflict_threshold` | 0.5 | 把红温冲突阈值降低。从零训练本身波动大，原来的阈值会让全程卡死在 red 状态，永远进不了 solid 稳态。 |
| `homeostatic_max_gain` | 2.0 | 放宽稳态增益上限，冷启动阶段统计量不准，上限卡太死会让可塑性一直被压制。 |

#### 预期效果
- 不会再出现 loss 指数级爆炸、正交损失几百的现象；
- 不再是“假零遗忘”（新任务学不动所以不覆盖），而是真的能学习新任务 + 保护旧任务；
- 最终 ACC 会从现在的 0.569 回升到接近 safe 版本的水平，遗忘依然显著低于 LoRA.

> 这一档的结论：**低秩从零训练场景下，最优配置就是「关 PEM + 弱正交 + 频繁 ReLoRA 合并」**，和低秩微调场景的最优配置高度一致。

## 二、【小改代码：适配冷启动】从根源解决问题
改动很小，但能从机制层面适配从零训练，效果比单纯调参好一个档次。

### 1. W0 初始化：从全零改成 Kaiming 初始化
这是单个收益最大的改动。
现在 W0 全零是万恶之源——所有依赖 W0 做参考的机制（正交、SPHeRe、PEM）全部量纲错乱。
改成和普通线性层一样的 **Kaiming 均匀初始化**：
```python
nn.init.kaiming_uniform_(self.W0, a=math.sqrt(5))
```
- 立刻给 W0 一个合理的初始表征分布；
- 正交惩罚、结构损失的参考系瞬间恢复正常，不需要手动预热；
- 训练初期的数值爆炸问题直接消失。

### 2. 相对正交惩罚：自适应 W0 模长
把固定的 `ortho_lambda` 改成：
```python
ortho_strength = ortho_lambda / (W0.norm() + 1e-4)
```
W0 模长小的时候惩罚自动减弱，W0 长大了惩罚自动跟上，从根源上解决冷启动阶段正交惩罚失真的问题，不用手动调 warmup。

### 3. 状态机自适应阈值
不要用固定的冲突/波动率阈值，改成：
> 取每个任务前 50 步冲突分数的 75% 分位作为红温阈值。

自动适配训练阶段和任务难度，从零训练和预训练微调都能用，不会出现阈值不匹配卡死状态的问题。

### 4. SPHeRe 强度自适应
和正交惩罚同理，结构损失也除以 W0 的迹做归一化，冷启动阶段自动减弱，不会一开始就炸。

#### 预期效果
- 训练全程数值稳定，机制正常流转；
- ACC 再提升 1~2 个百分点，接近标准 LoRA 的水平；
- 抗遗忘收益依然保留，整套机制真正开始工作，而不是互相打架。

## 三、【架构级改动：释放全部潜力】真正为从零训练设计
如果想让 Aeloru 在从零训练场景发挥出全部优势，需要跳出「低秩适配器」的框架，回到它的原生设计场景。

### 1. 去掉低秩约束，全参数从零训练
PEM、HGF、SPHeRe 这套机制原生就是为全权重网络设计的，低秩是后来为 LLM 微调做的移植。
- 直接让 r = 隐藏层维度，去掉低秩瓶颈；
- PEM 立刻从负贡献转正，开始发挥预测编码的自适应调制优势；
- HGF 门控、SPHeRe 结构保持全部工作在完整空间，不会被低秩压缩变形。

> 这才是 PEM 的主场：全参数、从头训练、多任务持续学习。之前实验验证的「PEM 转正」也正是在这个场景下成立的。

### 2. 分层差异化配置
不要全局一套参数，按层分工：
- **底层（特征提取层）**：关 PEM、强 SPHeRe、强稳态，负责稳定的基础特征提取；
- **顶层（任务适配层）**：开 PEM、高可塑性、弱正交，负责快速学习新任务。

符合认知科学的「分层可塑性」规律，也比全局统一配置效果好得多。

### 3. 渐进式秩扩张
从零训练不要一开始就固定死 r：
- 初始 r=4，随着任务增加逐步扩张到 8→16→32；
- 新任务分配新的低秩维度，不会挤掉旧任务的表征；
- 从根源上缓解低秩空间的容量瓶颈。

### 4. 累积式原型 PEM
不要每个任务重置原型，改成：
> 原型向量随任务逐步累积，旧任务原型保留，新任务原型叠加。

更适合从零开始的持续学习场景，原型是逐步建立的，而不是每个任务重新算。

## 总结与推荐
### 如果你现在就要跑一个合理的 fromscratch 结果
用第一档的调参方案 + 第二档的 Kaiming 初始化 W0，性价比最高：
```
--method aeloru-fromscratch
--neural_dynamics_iterations 0
--ortho_lambda 0.03
--lr 3e-4
--merge_every 200
--red_conflict_threshold 2.0
```
再把 W0 从全零改成 Kaiming 初始化，跑完就能得到一个**收敛正常、抗遗忘有效、ACC 合理**的结果，不再是现在的失效案例。
