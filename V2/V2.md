# AeloRu V2 — Cognitive Mechanisms Integration

**A**daptive **E**lastic **L**earning with **O**rthogonal **R**obust **U**nits

V2 integrates the full set of cognitive-science mechanisms into the AeloRu layer and
replaces the expensive Fisher estimation with a **closed-form, gradient-free** scheme
based on Hierarchical Gaussian Filtering (HGF).

> Closed-form gradient derivation (MSE → CE / BCE) lives in [`HGF_CE.md`](HGF_CE.md).

## What's New vs. V1

| Addition | Principle | Role |
| :--- | :--- | :--- |
| **PEM — Adaptive Lateral Connections** | Low-rank lateral inhibition | Feature decoupling & redundant-correlation suppression in the low-rank space. |
| **PEM — Homeostatic Plasticity** | Neuron-level adaptive gain | `g_i = 1/(running_var_i + 1e-5)` prevents weight explosion. |
| **HGF Closed-form Fisher** | Precision propagation | Replaces squared-gradient Fisher with closed-form precision; `O(d²) → O(d)` gating. |
| **HGF Volatility Coupling** | Dynamic learning rate | `ω += κ·(ε² − exp(ω))`, `lr_eff = 1/exp(ω)` adapts to concept drift. |
| **DLAM Spectral Sleep** | Offline consolidation | Spectral filtering of Hebbian traces; prune weak links + cross-layer prototype binding. |

### Dual 1-D HGF Plasticity Gate (key optimization)
The parameter-level Fisher mask `ΔW'' = ΔW' ⊙ 1/(1+γF)` needs `O(d_out·d_in)` memory
and a costly gradient path. V2 observes that `ΔW` only has `O(r(d_out+d_in))` degrees of
freedom and instead maintains two **1-D precision vectors** `π_out`, `π_in` (closed-form
from HGF `running_var` and input covariance `C_x`). Their outer product approximates the
2-D Fisher and gates both Hebbian updates and the weight increment — structurally
isomorphic to Hi-DoRA's `(m_x · m_yᵀ)` double 1-D modulation.

## Key Formulas

```
稳态增益      g_i   = 1 / (running_var_i + 1e-5)
侧向抑制      h'    = h - h @ Lᵀ,    dL/dt = η_lat · outer(h_mean, h_mean)
HGF 精度      π     = π_pred + π_prev · α² · (g')²
波动率        ω    += κ·(ε² - exp(ω)),   lr_eff = 1/exp(ω)
DLAM 核       A(t)  = (1+t)·(I + t·Σ)⁻¹
```

### Closed-form gradients (no autograd)
Only the output-layer local gradient `δ = ∂L/∂z` differs between losses; the adapter
backward chain is unchanged:

- **MSE**: `δ_MSE ≈ z − y_target`
- **Softmax-CE**: `δ_CE = p − y_target` (sum-gradient convention)

```
grad_B = δᵀ h' · (α/r),    grad_A = [(δ B) ⊙ 𝟙_{h>0}]ᵀ x · (α/r)
```

## Status & Caveats

- **Status**: 🔄 Theoretical integration. The PEM/homeostatic modules were designed for
  cognitive models trained from scratch.
- ⚠️ **Contrast-fairness bug** (found during V3 validation, see `V3/md/ex1.md`):
  `experiment_1.py` did **not** freeze the base model in the AeloRu branch, effectively
  running 494M full-parameter tuning — not comparable to peft LoRA. V3 fixes this by
  explicitly freezing the base and matching injected layer counts.
- ⚠️ PEM applied to the **full output dimension** (`d_out`) corrupts pretrained
  activations on real Transformers. V3 relocates PEM to the **r-dim low-rank feature
  space** (`pem_space="lowrank"`); V2's `output`-space PEM is only safe for
  from-scratch cognitive models (`AeloruConfig.cognitive_model()`).
